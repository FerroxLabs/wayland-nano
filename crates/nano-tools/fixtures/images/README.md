# Synthetic image-intake fixtures (P2a §12)

Every byte stream here is GENERATED by the test-module generator in
`crates/nano-tools/src/image.rs` (`mod tests`) — no real photos, no secrets.
The committed files are pinned copies of the generator output; the test
harness FAILS LOUDLY if a file on disk diverges from its generator (delete a
file to regenerate it, then commit the regenerated bytes with the generator
change that explains the difference).

Oversize cases (50 MiB + 1 B, capped-read) are generated in memory only and
never land here.

| File | Exercises |
|---|---|
| `valid.{png,jpeg,gif,webp}` | 4-format round-trip |
| `corrupt-crc.png` | flipped IDAT byte → CRC mismatch → `ImageInvalid` |
| `truncated.jpeg` | ends right after SOF0 (no tables/entropy/EOI) → `ImageInvalid` |
| `forged-extension.png.txt` | text bytes → sniff failure → `ImageInvalid` |
| `vector.svg.bin` / `bitmap.bmp.bin` | SVG / BMP → `ImageUnsupportedFormat` |
| `bomb-header.png` | 40,000×40,000 declared over 64 B → `ImageTooLarge` at the header probe, zero allocation |
| `dim-65536.png` | 65,536-edge (u32-overflow class) → `ImageTooLarge` |
| `downscale-3000.png` | 3000×3000 → downscaled under 2000 px / 1,048,576 px |
| `noisy-900k.png` | ~900 KiB incompressible → JPEG ladder under the 768 KiB base64 cap |
| `exif-gps-orient6.jpeg` | EXIF orientation 6 + GPS canary → oriented pixels, metadata structurally absent |
| `png-text-canary.png` | PNG `tEXt` canary → output chunks ⊆ {IHDR, PLTE, tRNS, IDAT, IEND} |
| `jpeg-com-canary.jpeg` | JPEG `COM` canary → output has no APP1/APP13/COM |
| `polyglot-png-zip.png` / `polyglot-jpeg-html.jpeg` / `polyglot-gif-js.gif` | trailing ZIP/HTML/JS payloads never reach the re-encoded output |
| `anim-1000f.gif` | 1,000-frame GIF → first frame only, `frames_dropped` |
| `anim.webp` | hand-built VP8X/ANIM/ANMF two-frame animated WebP → first frame only |
