<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| Trigger storm → admission/budget | An unbounded or unbudgeted retry path converts a Desktop loop into unbounded Nano spend. |
| Escalation mechanism → operator attention | An uncapped attention channel can be flooded to hide a real escalation in noise. |
| New vocabulary → frozen journal contract | Adding attention/retention ops to the session journal silently amends an owner-frozen contract. |
| Retention/tombstone sweep → replay authority | Sweeping live tombstones or ledger rows re-enables nonce replay or strands audit history. |

| T-04-16 | Tampering | control integrity | critical | mitigate | Signed controls reused unmodified; RaceLost vs terminal semantics; unsigned/replayed/wrong-activation negatives. |

Wall-time discipline:
1. CI is a confirmation, never a debugger. Local gates green before any push. A CI-only failure's next action is a minimal LOCAL reproduction of the failing predicate; a second CI push without a local repro is a rule violation.
2. Round-trip test before integration test: every new wire format / ledger record / state machine gets a serialize→parse (or apply→replay) round-trip unit test in the SAME commit as the type.
3. Cheapest distinguishing experiment: hypothesis sentence before attempt 2, and attempt 2 must be the smallest experiment discriminating the live hypotheses — never a full-pipeline rerun. Full suites run once per plan at the end, focused tests per task.
4. Per-plan wall-time tripwire: `wall_time_tripwire: "3 working days"` in frontmatter, plus a 45-minute diagnosis time-box per failure class, then handoff. Hitting the tripwire = stop + .continue-here.md = SUCCESS, not failure.
5. Machine-checkable handoffs: every .continue-here.md entry carries the exact next command AND its expected output, so a resumer verifies state with one command instead of re-deriving context.
