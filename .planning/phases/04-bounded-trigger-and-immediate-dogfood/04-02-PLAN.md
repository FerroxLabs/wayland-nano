## Trust Boundaries
| Boundary | Description |
|---|---|
| Ambiguous dispatch → operator | An ambiguity hidden in tool-refusal text but absent from receipts is un-auditable and un-reconcilable. |
| Reconciliation command → effect dispatch | A resolve path that can re-fire an effect converts manual reconciliation into an unbounded retry backdoor. |
| Wording → operator trust | A single surviving exact-once claim teaches operators to trust a guarantee the ledger does not provide. |
