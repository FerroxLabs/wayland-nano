## Trust Boundaries
| Boundary | Description |
|---|---|
| Harness provisioning → admission gate | A fixture shortcut that bypasses admission fabricates the entire dogfood claim. |
| Simulated Desktop trigger → sole-fire posture | The harness mints carriers but must never introduce or use an in-Nano firing path. |
| Harness output → report | Report numbers must trace to NDJSON/receipts; self-report is not evidence. |
| Fake-model determinism → repeatability | A nondeterministic run cannot distinguish architecture faults from harness noise. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04-25 | Elevation | unauthenticated dogfood | critical | mitigate | Every run provisions via phase2_fixture and traverses the real admission gate; enablement-less homes fail closed; preflight rejects unmarked binaries. |
| T-04-26 | Elevation | schedule reintroduction | critical | mitigate | Scheduled legs mint occurrence-keyed carriers only; sole-fire source-grep + behavioral row in the matrix; 04-01 assertions stay green. |
| T-04-27 | Repudiation | evidence integrity | high | mitigate | NDJSON + receipts + seed/binary-hash/home-manifest per run; report renders from evidence only. |
| T-04-28 | Tampering | negative-row dilution | high | mitigate | Crash/cancel/replay/remap/denial rows are mandatory matrix entries that fail, never skip, when absent. |
| T-04-SC | Tampering | dependencies | high | mitigate | No package changes; the harness uses the existing soak-fake-model feature seam. |

1. CI is a confirmation, never a debugger. Local gates green before any push. A CI-only failure's next action is a minimal LOCAL reproduction of the failing predicate; a second CI push without a local repro is a rule violation.
2. Round-trip test before integration test: every new wire format / ledger record / state machine gets a serialize→parse (or apply→replay) round-trip unit test in the SAME commit as the type.
3. Cheapest distinguishing experiment: hypothesis sentence before attempt 2, and attempt 2 must be the smallest experiment discriminating the live hypotheses — never a full-pipeline rerun. Full suites run once per plan at the end, focused tests per task.
4. Per-plan wall-time tripwire: `wall_time_tripwire: "3 working days"` in frontmatter, plus a 45-minute diagnosis time-box per failure class, then handoff. Hitting the tripwire = stop + .continue-here.md = SUCCESS, not failure.
