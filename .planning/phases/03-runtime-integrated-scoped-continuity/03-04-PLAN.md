<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| Legacy .md content → journaled MemoryWrite* ops | Migration is a trust-relevant transformation: a wrong tier assignment launders unvetted content into authority. |
| Live DB ↔ rebuilt DB | Any divergence (order, valid windows, agent_id) breaks the journal-is-authority contract. |
| Legacy journal vocabulary → retrieval surface | Replay-readable legacy ops must never become retrievable authority. |
| Post-migration legacy store → seam | A readable legacy path post-migration is a second, unmediated memory source. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-03-17 | Tampering | rebuild divergence | critical | mitigate | §11 bar 2 equivalence incl. agent_id, kill-mid-write, multi-journal coverage under the recorded topology. |
| T-03-18 | Elevation | legacy authority regain | critical | mitigate | Backstops remain; legacy names UnknownTool; hand-edited .md invisible; idempotent-or-refused re-migration. |
| T-03-19 | Repudiation | migration provenance | high | mitigate | Journaled ops with project/agent_id/source_trust and a counted, hashed receipt. |

Wall-time discipline:
1. CI is a confirmation, never a debugger. Local gates green before any push. A CI-only failure's next action is a minimal LOCAL reproduction of the failing predicate; a second CI push without a local repro is a rule violation.
2. Round-trip test before integration test: every new wire format / ledger record / state machine gets a serialize→parse (or apply→replay) round-trip unit test in the SAME commit as the type.
3. Cheapest distinguishing experiment: hypothesis sentence before attempt 2, and attempt 2 must be the smallest experiment discriminating the live hypotheses — never a full-pipeline rerun. Full suites run once per plan at the end, focused tests per task.
4. Per-plan wall-time tripwire: `wall_time_tripwire: "2 working days"` in frontmatter, plus a 45-minute diagnosis time-box per failure class, then handoff. Hitting the tripwire = stop + .continue-here.md = SUCCESS, not failure.
5. Machine-checkable handoffs: every .continue-here.md entry carries the exact next command AND its expected output, so a resumer verifies state with one command instead of re-deriving context.
</verification>
