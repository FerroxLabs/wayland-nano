| Boundary | Description |
|---|---|
| Signed carrier fallback field → runtime degradation | An unpinned or coerced fallback silently widens continuity beyond what the issuer signed. |
| Host config → resolved MemoryPolicy | A lenient parse (unknown enum, Global alias) re-creates the removed ReadScope::Global. |
| Policy default → seam behavior | A default-enabled policy turns memory on for every authenticated session without an explicit decision. |

| T-03-SC | Tampering | dependencies | high | mitigate | Only the owner-approved existing workspace nano-memory edge and pinned TOML parser are added; no upgrades or unrelated package changes. |
