## Trust Boundaries
| Boundary | Description |
|---|---|
| Signed carrier fallback field → runtime degradation | An unpinned or coerced fallback silently widens continuity beyond what the issuer signed. |
| Host config/env → resolved MemoryPolicy | A lenient parse (unknown enum, Global alias) re-creates the removed ReadScope::Global. |
| Policy default → seam behavior | A default-enabled policy turns memory on for every authenticated session without an explicit decision. |

| T-03-08 | Tampering | policy parse | high | mitigate | deny-unknown strict parse; Global/unknown source_trust/agent_scope are typed errors (§5); validate_policy fail-closed. |

| T-03-SC | Tampering | dependencies | high | mitigate | No package changes; TOML parsing reuses the existing config-schema posture if a file source is chosen. |
