<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| Admitted token → seam identity | Re-deriving agent_id anywhere downstream of admission can desync wire principal_id from physical rows. |
| Model tool surface → memory store | Any model-reachable write path outside commit_proposal launders tier or bypasses screening. |
| Journal topology → durability/rebuild | An implicit or forked journaling choice breaks kill-mid-write recovery or rebuild equivalence. |
| Activated seam → legacy quarantine | Wiring the new seam must not reopen the legacy .md store for authenticated sessions. |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-11 | Spoofing | identity binding | critical | mitigate | principal_id→agent_id bound once at admission, passed as opaque typed value; byte-for-byte (D3-02); typed negatives on mismatch. |
| T-03-12 | Elevation | model write path | critical | mitigate | Proposals only via commit_proposal; force-capped ModelInference; deterministic screening; MediationRequired negatives on every other surface. |
| T-03-13 | Tampering | journal topology | high | mitigate | Explicit decision record before wiring; fault-injection + rebuild-equivalence proof obligations carried into 03-04. |
| T-03-14 | Elevation | legacy re-open | critical | mitigate | Legacy tool names stay UnknownTool; quarantined executor retained for unauthenticated paths; extended quarantine suite. |
| T-03-15 | Information Disclosure | cross-scope retrieval | critical | mitigate | Policy-driven retrieve with partition predicates in passes 1-2; mem-sec cards (03-01) are the adversarial oracle. |
| T-03-SC | Tampering | dependencies | high | mitigate | No package changes; seam lives in nano-cli using existing nano-memory/nano-session edges. |
